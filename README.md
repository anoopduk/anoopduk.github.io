# A. Anoop — personal website

Source for [anoopduk.github.io](https://anoopduk.github.io/). The personal site
contains biography, teaching, talks and authored writing; group research,
software and publications belong on [AnoopLab](https://anooplab.github.io/).

Writing is published from Markdown files in `writing/`. Every public article
must define a unique `title`, `description`, `date` and `permalink` in its front
matter. Add an `image` when a page-specific social preview is available. For a
substantive revision, record `seo.date_modified` as an ISO 8601 date.
